개념12 – 인덱싱, 슬라이싱, 스트라이딩 ([시작:끝:간격])

- 인덱싱: 한 글자(한 원소)를 꺼낸다. 번호는 0부터 세고, -1 은 맨 끝이다.

s = 'abcdef'
s
'abcdef'
s[0]
'a'
s[-1]
'f'

- 슬라이싱 [시작:끝]: 여러 글자를 잘라 낸다. 끝 번호는 포함하지 않는다.

s[0:3]
'abc'
s[2:]
'cdef'
s[:2]
'ab'

- 맨지막원소가 끝점일경우 생략가능하다.

s[0:]
'abcdef'
s[1:]
'bcdef'
s[2:]
'cdef'

- 맨처음원소가 시작점일 경우 생략가능하다.

s[:2]
'ab'
s[:3]
'abc'
s[:4]
'abcd'

- 모두 생략할수도있다.

s
'abcdef'
s[::]
'abcdef'

- 스트라이딩 [시작:끝:간격]: 간격만큼 건너뛰며 꺼낸다.

s[::2]
'ace'
s[1::2]
'bdf'

- 간격을 -1 로 주면?

s[::]

개념13 – range 와 append 로 리스트 만들기

- range(시작, 끝) 은 시작부터 끝 바로 앞까지의 수를 차례로 준다.

for n in range(3, 8):
    print(n)

- 빈 리스트(또는 처음 몇 개만 든 리스트)에 append 로 하나씩 붙여 나갈 수 있다. x[-1] 과 x[-2] 는 맨 끝, 끝에서 두 번째 원소다.

an = [1, 1]
for n in range(3, 11):
    an.append(an[-1] + an[-2])
an

문제1 – for 문을 사용하여 아래와 같은 수열을 정의하라. (\(a_1, \dots, a_{100}\) 까지 선언할 것)

  • \(a_1 = a_2 = 1\)
  • \(a_n = a_{n-1} + a_{n-2}\) where \(n \geq 3\)

문제2 – 2021 카카오 채용연계형 인턴쉽 기출문제

출처: https://school.programmers.co.kr/learn/courses/30/lessons/81301?language=ruby

네오와 프로도가 숫자놀이를 하고 있습니다. 네오가 프로도에게 숫자를 건넬때 일부 자릿수를 영단어로 바꾼 카드를 건네주면 프로도는 원래 숫자를 찾는게임입니다. 다음은 숫자의 일부 자릿수를 영단어로 바꾸는 예시입니다.

1478 --> "one4seveneight"
234567 --> "23four5six7"
10203 --> "1zerotwozero3"

이렇게 숫자의 일부 자릿수가 영단어로 바뀌어졌거나, 혹은 바뀌지 않고 그대로인 문자열 s가 매개변수로 주어집니다. s가 의미하는 원래 숫자를 return 하도록 solution 함수를 완성해주세요.

참고로 각 숫자에 대응되는 영단어는 다음 표와 같습니다.

숫자 영단어
0 zero
1 one
2 two
3 three
4 four
5 five
6 six
7 seven
8 eight
9 nine

- 제한사항

  • 1 ≤ s의 길이 ≤ 50
  • s가 “zero” 또는 “0”으로 시작하는 경우는 주어지지 않습니다.
  • return 값이 1 이상 2,000,000,000 이하의 정수가 되는 올바른 입력만 s로 주어집니다.

- 입출력 예

s result
“one4seveneight” 1478
“23four5six7” 234567
“2three45sixseven” 234567
“123” 123

- 입출력 예 설명

  • 입출력 예 #1 – 문제 예시와 같습니다.
  • 입출력 예 #2 – 문제 예시와 같습니다.
  • 입출력 예 #3 – “three”는 3, “six”는 6, “seven”은 7에 대응되기 때문에 정답은 입출력 예 #2와 같은 234567이 됩니다. 입출력 예 #2와 #3과 같이 같은 정답을 가리키는 문자열이 여러 가지가 나올 수 있습니다.
  • 입출력 예 #4 – s에는 영단어로 바뀐 부분이 없습니다.

2. 종합

Downloads/prob/prob1200.txt 에는 문제 1200개가 들어 있습니다. 저는 농촌진흥청에 이 과목 시험문제 12개를 냈고, AI에게 비슷한 문제 1188개를 더 만들게 해서 함께 섞었습니다. 제가 실제로 낸 문제 12개를 찾아 보세요.

  • 문제와 문제 사이는 --- 로 구분되어 있습니다.
  • 문제의 글자는 모두 거꾸로 적혀 있습니다.
  • 문항 번호는 카카오 기출처럼 숫자의 일부가 영단어로 적혀 있습니다. (예: 1478 → one4seveneight)
  • 제가 낸 문제는 문항 번호가 피보나치 수인 것뿐입니다. 번호가 피보나치 수가 아니면 진짜 문제가 아닙니다.
  • 피보나치 수열은 \(a_1 = a_2 = 1\), \(a_n = a_{n-1} + a_{n-2}\) 로 정의합니다. 문항 번호는 아무리 커도 \(a_{100} = 354224848179261915075\) 를 넘지 않습니다.
